# Jugabilidad

## Descripción de la sección

La jugabilidad explica **qué hace el jugador, qué recibe a cambio y cómo evoluciona la experiencia**.

## Bucle principal de juego

Describe el ciclo que se repite durante la experiencia.

**Ejemplo conceptual:**

`Explorar → Encontrar desafío → Resolver → Obtener recompensa → Mejorar → Explorar`

**Bucle del proyecto:** Explorar -> Encontrar un Enemigo -> Derrotar al enemigo -> Obtener Recompensa -> Mejorar Estadísticas -> Explorar

## Acciones principales del jugador

| Acción               | Propósito                                                                                                                                    | Resultado                                                                          |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Explorar             | Descubrir el mundo, encuentros opcionales y recompensas.                                                                                     | Obtener recompensas, combatir enemigos y obtener mejoras únicas para el personaje. |
| Combatir             | Interactuar con el sistema de combate, usando diferentes habilidades para derrotar a grupos de enemigos o mini-jefes.                        | Recibir recompensas y usarlas para mejorar al personaje.                           |
| Mejorar Estadísticas | Aumentar las estadísticas del jugador y sus compañeros, permitiendo volverse más fuerte y ayudando a derrotar más fácilmente a los enemigos. |                                                                                    |
